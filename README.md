## v1.4 — выделение, горячие клавиши и мягкие UI-звуки

Основано на `main` **f6ddd2a**. Музыка Sky High и последние изменения её кнопки сохранены.

| Действие | Управление |
|---|---|
| Выделить область | Потянуть рамку с пустого места |
| Добавить область | Shift + рамка, в том числе начиная поверх объекта |
| Добавить / убрать один | Ctrl/⌘ + клик |
| Выбрать всё | Ctrl/⌘ + A |
| Переместить группу | Тянуть любой выделенный объект |
| Повернуть на 15° | R; Shift+R — в обратную сторону, включая удержание мышью |
| Отменить / повторить | Ctrl/⌘+Z; Ctrl/⌘+Shift+Z или Ctrl+Y |
| Копировать выделение | Ctrl/⌘+D |
| Удалить | Delete / Backspace, кнопка или возврат в подсвеченную палитру |
| Точный сдвиг | Стрелки: 12 px мира; Shift: 40; Alt: 1 |
| Отмена жеста | Escape; отпускание за пределами холста, кроме палитры/корзины |
| Пауза / сохранения / справка | Пробел / Ctrl/⌘+S / H или ? |

Кнопки над холстом доступны и на телефоне. «Выделение рамкой» заменяет Shift при касании. R/Z/A/D/S работают по физической клавише, независимо от русской раскладки. В полях ввода сохраняется обычное редактирование текста/чисел. Выделяются логические объекты: многотельный рецепт — одна установка, переносимая целиком; группа не склеивается в рецепт случайно.

История — **60 действий в памяти вкладки**, не запись каждого физического шага. Перенос с поворотом — одна отмена. Возвращаются объекты, параметры, положение, скорость и время снимка; открытия и текущие настройки аудио/отображения сохраняются. После перезагрузки страницы история пуста, сохранения v1 поддерживаются (добавлены необязательные rotation, selectedIds, anchors/motions).

Поворот меняет поле и его область, ось пружины, направление скорости/приложенной силы. Масштаб скорости от переноса мышью не добавляется. Симметричное B не меняет знак от поворота в плоскости; пол и земная тяжесть F=mg остаются вниз. Аналитические установки поворачиваются целиком.

Заменены только click/craft/discovery/remove/error: натуральные деревянные/тканевые удары Kenney CC0, сглаженные атаки, срез высоких частот 1800 Гц и более тихие пики. **drop/оба impact/absorb/blackhole/sky-high.mp3 сохранены побайтно**, как и уровни одобренных эффектов. Источники и обработка: `public/audio/credits.json`; воспроизводимый импорт: `python scripts/soften-ui-audio.py --cache DIR` (Python + ffmpeg, не нужны для обычного запуска).

# Formula Alchemy — редактор экспериментов (1.4)

Модульная браузерная физическая песочница: React + TypeScript + Vite, Matter.js, Canvas 2D и KaTeX. **48 рецептов**, реальные области E/B/g и прямое перетаскивание визуализаций. Без обязательного бэкенда.

## Запуск

Node.js 22.12+:

```bash
npm ci
npm run dev
```

```bash
npm run check
npm run verify:dist
npx playwright install chromium
npm run test:e2e
```

`check` выполняет TypeScript, тесты и production build. E2E запускает настоящую HTTP-сборку под `/formula-alchemy/` на desktop и mobile Chromium. `preview:pages` запускает просмотр сборки.

## Скорости и новые звуки

Небольшие подписи скорости у движущихся тел/зарядов, спутника, груза маятника/пружины и стержня СТО. В инспекторе показывается текущая скорость, а не заданная начальная. Переключатель **«Скорости тел»** независим от векторов и сохраняется в JSON/localStorage; старые v1-файлы автоматически получают значение `true`.

Физические тела: м/с, спутник: км/с (без анимационного множителя ×200), стержень: доля c. Для волн подпись явно говорит «волна» — это скорость распространения. Поля, неподвижные источники, декоративная пыль, тепловые точки и маркеры тока не получают выдуманную скорость. Скорость перетаскивания и ускорение воспроизведения не выдаются за физическую скорость. Надписи без фона, с подавлением пересечений и лимитом 7 на мобильном / 14 на ПК.

**10 звуков Kenney CC0** из Interface Sounds, Impact Sounds и Sci-fi Sounds: выбор, размещение, соединение, открытие, удаление, ошибки, столкновения и чёрная дыра. WAV-файлы включены в `public/audio`; во время игры они загружаются только с самого сайта, один раз после первого действия. Оригинальные лицензии, имена исходников и хеши — `public/audio/credits.json` и `LICENSE-*.txt`.

Громкости согласованы, частые удары и поглощения ограничены, одновременно не больше 8 эффектов. Отключение звуков гасит текущие и отменяет ожидающие загрузки эффекты. Кнопка музыки включает зацикленный трек Elektronomia — Sky High [NCS Release], независимо от звуковых эффектов. MP3 встроен в `public/audio` и загружается с сайта только после включения; кредит указан в справке и `public/audio/credits.json`. Ошибка загрузки звука не останавливает игру. Для сопровождения, не обычного запуска: `python scripts/import-cc0-audio.py` повторно скачает оригиналы с сайта автора по закреплённым SHA256 и потребует ffmpeg.

## Сохранённое управление

С холста удалены точки-ручки, карточка выбранного эффекта и формулы поверх объектов. Буквы рисуются без рамок, кружков и подложек. Нажмите на сам объект — формула и численные параметры появятся в инспекторе справа, на телефоне — в нижней панели. При сборке формула автоматически не появляется на поле.

Зажмите само тело, область поля, чёрную дыру или лабораторную схему. Положение меняется во время движения, до отпускания; место захвата сохраняется. Аналитические схемы перемещаются целиком. «Развернуть лабораторию» открывает крупный опыт, «На холст» возвращает общий мир.

E ускоряет заряды по qE/m внутри видимой области. B поворачивает движущийся заряд, сохраняя модуль скорости; точки обозначают направление из экрана, крестики — в экран. Покоящийся заряд B не разгоняет. Знак заряда, B, направление E, размеры областей и начальная скорость задаются в инспекторе. g действует на тела в своей области.

Новые рецепты: G+M — источник тяготения, G+M+r — поле обратных квадратов, E+B — скрещённые поля, mu_m+I — круглый виток. `mu_m` — магнитная проницаемость, обычный `mu` остаётся коэффициентом трения. G отдельно — постоянная, а не источник.

Притяжение чёрной дыры направлено к центру, без бокового двигателя. Декоративная пыль не сталкивается с телами и тоже поглощается. Захват проверяется между шагами, поэтому быстрое тело не должно пролетать сквозь горизонт. Поглощаются также буквы и области полей. Интерфейс остаётся доступным.

Изменение массы тела и силы поля не пересоздаёт объекты. У пола исправлена реакция опоры: тело успокаивается после затухающих отскоков. Отдельно исправлены нейтральная плавучесть, направление силы Ампера, обратный ход RC-маркеров, неподвижный старт стержня СТО, переполнение энергетического столбца и сохранение пыли без подписи.

## Управление и сохранения

Пробел — пауза, Delete — удаление, квадратные скобки — выбор, стрелки — перемещение, Escape — отмена переноса, Ctrl/Cmd+S — сохранения. На телефоне короткое нажатие открывает инспектор; перетаскивание его не раскрывает.

Восемь слотов, автосохранение и JSON-импорт/экспорт. Старые v1 сохраняют совместимость; отсутствующие параметры одиночных букв получают значения по умолчанию. Повреждённый слот не блокирует остальные; recovery-ключи сохраняют исходные данные перед перезаписью. Временные эффекты и скорость затягивания аналитических схем не сохраняются.

## Архитектура

`core/` — каталог, вычисления, состояние, сохранения и определения элементов. `physics/` — Matter.js, поля и шаг времени. `rendering/` — Canvas, частицы и hit-геометрия; `labs/` — отдельные аналитические опыты. `components/` — панели и инспектор. `app/usePointerCraft.ts` — единое управление реальными объектами. `editor/` — выделение, геометрия групп и история команд; `app/useEditorShortcuts.ts` — горячие клавиши; `audio/` — семплированные эффекты и независимая музыка Elektronomia — Sky High; `physics/speedReadings.ts` — физические скорости; `rendering/speedLabels.ts` — подписи без UI-плашек.

Новый рецепт требует каталог, вычислитель, обработчик и тест. Все исходные 44 рецепта сохранены; четыре полевых рецепта добавлены отдельно в `core/extraRecipes.ts`.

## GitHub Pages

Дополнение подготовлено в ветке `feat/editor-shortcuts-soft-audio`. `main` автоматически не заменяется. После проверки объедините ветку с `main` либо перенесите файлы архива в корень существующего репозитория, без дополнительной вложенной папки. В Settings → Pages выберите GitHub Actions. Существующий `deploy.yml` проверит и опубликует сайт после push в main.

Vite использует `base: './'`; тесты открывают именно путь проекта `/formula-alchemy/`. Сохраняйте `package-lock.json`. Скрипт `publish:github` предназначен для создания нового репозитория, не для перезаписи существующего.

## Проверки и ограничения

Текущая база: `f6ddd2a` из main. Версия 1.4 прошла 178 unit/physics-тестов, сборку и 60 браузерных HTTP-сценариев на ПК/мобильном Chromium без повторных попыток. Результаты, точный коммит, ограничения и ссылка на Actions — в `docs/QA-editor.md`. Исторические отчёты: `docs/QA-speed-audio.md` и `docs/QA.md`.

48 опытов не заменяют весь школьный курс. Механические тела и области E/B/g/GM взаимодействуют в общем мире; тепловые, оптические и квантовые схемы не объединены в один универсальный решатель. Области полей имеют условно резкие границы. Поле витка использует центральное B на диске, не полный интеграл Био—Савара. Поле прямого провода I лежит в плоскости, его трёхмерное отклонение заряда не моделируется.

Чёрная дыра — художественная модель, радиус Шварцшильда в инспекторе вычисляется отдельно. Нет решения ОТО/CFD, произвольного конструктора цепей и поглощения интерфейса. Некоторые равновесные сцены могут быть неподвижны. Мобильный мир сохраняет соотношение сторон и может оставлять свободное пространство; реальный Safari/iPhone и FPS слабых устройств не проверялись.
