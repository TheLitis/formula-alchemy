# Границы моделей

Актуальные описания находятся в README.md и полях `description`, `effect`, `model`, `params` каталогов `src/core/catalog.ts` и `src/core/extraRecipes.ts`.

Мир: 1000×680, 32 px = 1 м, пол y=640, фиксированный шаг Matter.js 1/120 с. Временное удержание при drag не является физической силой. Отскоки частично неупругие.

E: qE/m внутри области. B: вращение скорости на (q/m)B dt с сохранением нормы; положительное B направлено из экрана. Координата y Canvas растёт вниз. Области имеют условно резкие границы. Скрещённые поля применяются последовательно; точность магнитного вращения не означает точное решение произвольного совместного движения E+B.

I рисует касательное поле в плоскости. Движение заряда из плоскости не рассчитывается. Виток использует центральное B на всём диске. G — константа; источником становится GM. Тяготение GM сглажено внутри 0,7 м.

У чёрной дыры вычислительный радиус Шварцшильда отделён от художественного экранного радиуса и силы захвата. Пыль — неконфликтующие сенсоры. Проверка пересечения горизонта между шагами предотвращает сквозной пролёт. UI не поглощается.

Плавучесть — затухающее приближение к равновесию, не CFD. При равных плотностях и нулевой начальной скорости центр остаётся на месте. Фаза RC-маркеров — интеграл условной скорости, не произведение времени на текущий ток. Энергетический индикатор использует явно положительную опорную энергию.

Оптические точки — замедленные маркеры реальных лучей, не расчёт времени полёта фотонов. Схемы можно переносить целиком, но не все процессы взаимодействуют между собой.
